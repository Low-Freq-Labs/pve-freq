# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/Low-Freq-Labs/pve-freq/security/advisories/new)
for this repository. Do not attach credentials, private keys, live configuration
or unredacted operational captures to a public issue.

Security-sensitive areas include authentication, role and scope checks, credential
storage, SSH/native transport, installation and infrastructure operation custody.
Report the exact source revision, affected path and a bounded reproduction using
fictional data where possible. Source publication and isolated checks do not
establish production security or universal infrastructure correctness.
